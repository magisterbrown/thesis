\section{Fourier Transform}
In 1822 Fourier claimed in (cite  Joseph Fourier § The Analytic Theory of Heat) that any function can be decomposed into sum of differnt of sine functions. Sine functions define different frequencies. It led to the development of the Fourier Transform. Fourier transform is a transformation that takes function as an input and outputs another function that defines magintude of each frequency $k$ is present in the Transform. 
\begin{equation}
    \hat{f}(k) = \int_{-\infty}^{\infty} f(x)\, e^{-2\pi i k x}\, \mathrm{d}x,
    \label{eq:ft}
\end{equation}
However, application of it requires continious function as an input.
\section{DFT}
Most of the signals that exists in the real world and we want to analyze. Are produced by unknow functions and we can only sample them. To express sampled data as frequencies we should sample it and apply Discrete Fourier Transfrom algorithm. It estimates how each frequency of interest matches all points. 
 \begin{equation}
      f_k = \sum_{j=0}^{N-1} c_j\, e^{-2\pi i\, jk/N}, \qquad k = 0, \dots, N-1.
      \label{eq:dft}
  \end{equation}

\section{Complexity and FFT}
DFT algorithm is applicable to any sets of uniformly distributed points. but is Complexity is $NM$ where N is number of points and M is nuber of output modes. Quadratic Complexity limits usability of DFT only to small datasets. James Cooley and John Tukey (add citation) in 1965 demonstrated there exists a redundancy in computing DFT for multiple frequencies at the same time. and total computation for magintudes in N frequencies from N samples can be done in $\mathcal{O}(N \log N)$. But, it requires frequencies of interest and samples to have uniform gaps in between, because  
FFT implementation widly extended applications of DFT. First of them allowing to process large amounts of data of earth vibrations and to distinguish between regular earth quakes and Soviet nuclear tests. 

\section{NUFFT}
However, sometimes we want to analyzed non uniformly distanced data. It has many applications (Several imaging methods, including magnetic resonance
imaging (MRI) [57, 35], X-ray computed tomography (CT) [18], ultrasound diffrac-
tion tomography [9], and synthetic aperture radar [3], citations from paper "A PARALLEL NON-UNIFORM FAST FOURIER TRANSFORM
LIBRARY BASED ON AN “EXPONENTIAL OF SEMICIRCLE”
KERNEL" pleas recite them) For example, In this cases Non uniform Discrete Fourier Transform NUDFT is possible, but there is no way to reduce Complexity from $\mathcal{O}(N^2)$ to $\mathcal{O}(N \log N)$ without loosing any information. Goal of NUFFT algorithm is to do exactly that: provide approximation of NUDFT result under some error tolerance in lower compute time. It is achieved by first projecting non uniform points onto uniform grid and then run a regular FFT with scaling afterwards. So Complexity goes down from $\mathcal{O}(NM)$ to $\mathcal{O}(N + M \log M)$ where each point is projected using spreading operation and then regular FFT computes result, that are processed with deconvolution to rescale them. There are also 2 extra type of NUFFT. Type 2 processes uniformly sampled points and outputs frequencies of non uniform locations so it includes pre-correction then FFT finally followed by deconvolution. Finally type 3 combines these 2 and processes non uniform points to return non uniform frequency magintudes. 

  \begin{align}
      \text{Type 1 (nonuniform to uniform):}\quad
      & f_{\mathbf{k}} = \sum_{j=1}^{M} c_j\, e^{\pm i\, \mathbf{k} \cdot \mathbf{x}_j},
      && \mathbf{k} \in I_{\mathbf{N}}
      \label{eq:type1} \\
      \text{Type 2 (uniform to nonuniform):}\quad
      & c_j = \sum_{\mathbf{k} \in I_{\mathbf{N}}} f_{\mathbf{k}}\, e^{\pm i\, \mathbf{k} \cdot \mathbf{x}_j},
      && j = 1, \dots, M
      \label{eq:type2} \\
      \text{Type 3 (nonuniform to nonuniform):}\quad
      & f_l = \sum_{j=1}^{M} c_j\, e^{\pm i\, \mathbf{s}_l \cdot \mathbf{x}_j},
      && l = 1, \dots, N
      \label{eq:type3}
  \end{align}


\begin{equation}
    f_{\mathbf{k}} = \sum_{j=1}^{M} c_j\, e^{\pm i\, \mathbf{k} \cdot \mathbf{x}_j},
    \qquad \mathbf{k} \in \mathbb{Z}^d,\; -\frac{N_i}{2} \le k_i < \frac{N_i}{2},
    \label{eq:nudft}
\end{equation}

\section{FINUFFT}
FINUFFT is an implementation of NUFFT by Flat Iron institute. It implements all steps required for NUFFT transforms except FFT step itself. Instead it provieds options to choose custom backend for FFT currently FFTW and DUCC are available (Please cite these 2). FINUFFT implementations steps using multiprocessing and highly optimized simd loops. Besides, it exposes for user multiple configuration parameters that allow to tune performance on specific cpu and data combination. These parameters are: Upsampling factor (sigma) - a balancing constant that sets how much FFT algorithm should oversample frequencies beatty2005 showed first that it is possible to set it to values other than 2, it allows to trade off work during spreading agains work during FFT. Maximum subproblem size is a batch size, because when spreading on the multiprocessor points are first split into batches and then distributed between workers. Sorting is an option that helps to group points in batches that are located near each other. Atomic update is threshold option that affects a step of sriting back results of processed batch to shared grid. It sets a threshold number of threads below which shared results grid is protected by a lock while when number of threads above threshold implementation of write back swithces to lock-free algorithm (add citeation to what is a lock free algorthim I had before) implemented using atomic compare and swap (CAS) instructions. \section{Quality Degradation}
As all NUFFT implementations provide only an approximation of NUDFT expected error bound needs to be estimated. Dutt–Rokhlin [12] gave the first rigorous
analysis of this error bound. FINUFFT paper also provides rigorous analysis of an error called Kernel error that measures lost information at the step of projecting points to uniform grid and includes truncation and aliasing. First term truncation happens because each point has some magnitude that is 
added to nearby grid cells. Further grid cell is from point less weight point magnitude has in a total sum of values in the grid cell. Relation between distance and a weight decay is called a kernl and for example in FINUFFT this realtion is defined by (give a formula). At some distance weight of a point becomes very small instead of adding it to grid points afar we just truncate computation. Truncation error comes from skipping calculation for point far away. Second is an aliasing error when non uniform points are projected on uniform grid very high frequencies become indestinguishable forexample if grid has size N then frequency k+N will look exactly like frequency k, and called k value will not represent the truth. FINUFFT rigorously estimates this error for "Exponential of Semicircle" kernel. Lowering upsampling factor increases error because then number of cells in FFT grid get smaller so more frequencies become indistinguishable at the same time lower upsampling factor sets increases kernel width according to (add formula) to partially compensate for growing aliasing error with reducing truncation error. However, some lower tolerances are not achivable with default upsampling factor 1.25 and require higher lower bound. But all valus in between lower bound and 2 achive expected tolerance and can be varied to increase perfromance. 
Howerver, kernel error esitmated assuming comutation in real numbers while machine operations in double or floating percision introduce some error overhead above.
Finally, storing point coordintates in machine precision instead of real numbers gives other kind or error called phase error.
To conclude, kernel error is most singinficatn and analyzed error source while contributions from other error sources come from machine precision and require experimental measurements.
