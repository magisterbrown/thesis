\section{Memory traffic of the measured configurations}
\label{app:traffic}

Table~\ref{tab:app_traffic} lists the 360 distinct configurations against which the memory traffic estimate of the spreading stage, Equations~\eqref{eq:spread_reads} and~\eqref{eq:spread_writes}, was checked: the $54$ test transforms of Table~\ref{tab:selection_results} with uniformly and with exponentially distributed points, each with the library defaults, with the selected configuration, and with the configurations selected by earlier versions of the procedure, on $20$ threads. Each configuration appears once, even where several versions selected it. The measured values are the DRAM lines read and written per nonuniform point, counted by the memory controllers (median of the runs); the estimated ones are those of the equations, with the ramp ends of Equation~\eqref{eq:traffic_ramps}. The last column is the estimate of reads plus writes divided by the measurement. The median error is $7\%$ and the 90th percentile $19\%$.
