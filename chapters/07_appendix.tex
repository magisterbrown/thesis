\subsection{Test Hardware}

All tests in this appendix were performed on an Intel Xeon E5-2698 v4 CPU (2.20\,GHz, 20 cores / 40 threads, single socket, 50\,MiB L3 cache).

Table~\ref{tab:maxsp_all_sweeps} collects the empirically best subproblem size $S_{\max}$ found across all parameter sweeps performed during this work on a local workstation search, across a range of problem sizes $M$, thread counts $T$, precisions, tolerances, transform dimensionalities, and transform types. Each row reports the fastest $S_{\max}$ found by an Optuna search (typically 40 trials of 5 benchmark iterations each) together with its wall-clock time and the time at the legacy default $S_{\max}=10^5$, for comparison.

The \emph{subproblems/thread} column is computed as $M / (S_{\max} \cdot T)$, i.e.\ the total point count divided by the subproblem-size cap and evenly split across threads. This is an approximation: it ignores the spatial binning granularity that determines the actual number of subproblems generated at runtime, so it should be read as a rough proxy rather than an exact count.
