\chapter{Extra performance evaluation results.}
\label{app:maxsp_sweeps}

This appendix collects results that support the main chapters but are too
large to include there: the spreading-cost sweep over the upsampling factor for
every configuration and tolerance, the configuration selected and the speed-up
obtained for each of the $54$ test transforms, the same with only $S_{\max}$
selected, and the measured and estimated
memory traffic for every configuration used to check the traffic model. All
results were measured on the platform described in Section~\ref{sec:platform}.
