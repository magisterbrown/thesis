\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Nonuniform fast Fourier transforms are widely used for image reconstruction,
data analysis and the numerical solution of differential equations. FINUFFT is
one of the fastest and most widely used implementations, but its parameters are
fixed defaults, tuned once by its developers, while the transforms it performs
vary in dimension, point density, accuracy and thread count. 

The aim of this thesis is to determine how FINUFFT's parameters affect its
running time and to derive models that select their values before a transform
runs.

We instrument FINUFFT so that the cost of each stage of a transform can be
measured separately, using timers inside its parallel region and hardware
performance counters. A joint search over six parameters estimates how much
faster a tuned configuration can be than the defaults. For the upsampling
factor, the sort bin size and the maximum subproblem size, we derive
closed-form performance models and validate them against measurements.

Every parameter affects performance nonlinearly, trading the cost of one stage
against another. The joint search finds a configuration $23\%$ faster than the
defaults. The upsampling factor model captures the trade-off between the FFT
and spreading stages. A selection procedure for the bin size and maximum
subproblem size, built on these models, achieves $1.50$ times higher throughput
than the defaults on multithreaded transforms.

Each trade-off is governed by the
cache sizes and the properties of the transform. For the bin size and maximum
subproblem size, this is enough to choose good values before the transform
runs. The gains are largest for multithreaded transforms, where spreading is
limited by memory bandwidth.

\noindent\textbf{Keywords:} FINUFFT, nonuniform FFT, parameter selection, performance analysis
