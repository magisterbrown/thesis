\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Nonuniform fast Fourier transforms are widely used for image reconstruction,
data analysis and the numerical solution of differential equations. FINUFFT is
one of the fastest and most widely used implementations, but its configuration
parameters take fixed default values, while the transforms it performs vary in
dimension, point density, accuracy and thread count. How these parameters affect
the cost of each stage of a transform, and how good values could be chosen
without a search, has not been explained.

The aim of this thesis is to determine how FINUFFT's parameters affect its
running time and to derive models that select their values before a transform
runs.

FINUFFT was instrumented so that the cost of each stage of a type-1 transform
could be measured separately, using timers inside its parallel region and
hardware performance counters. A joint search over six parameters estimated how
much faster a tuned configuration can be than the defaults. For the upsampling
factor, the bin dimensions and the maximum subproblem size, closed-form
performance models were derived and validated against measurements.

The upsampling factor, the maximum subproblem size and the bin dimensions were
each found to trade the cost of one stage against another, so that their best
values lie between the extremes. The joint search found a
configuration $23\%$ faster than the defaults. The upsampling factor model
captured the trade-off between the FFT and spreading stages. A selection
procedure for the bin dimensions and the maximum subproblem size, built on these
models, achieved $1.50$ times higher throughput than the defaults on
multithreaded transforms.

Where each trade-off balances is set by the cache sizes of the machine and the
properties of the transform. Knowing these is enough to choose good values for
the bin dimensions and the maximum subproblem size before the transform runs.
The gains are largest for multithreaded transforms, where spreading is limited
by memory bandwidth.
