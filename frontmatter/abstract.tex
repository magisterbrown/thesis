\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

FINUFFT is among the fastest libraries for the nonuniform fast Fourier transform. Its is heavily optimised, but its behaviour is also governed by a small set of configuration parameters that the library fixes from built-in heuristics, and whose effects have not been studied systematically.

This thesis measures what those parameters do. The library is instrumented so that the cost of each stage of a transform can be attributed separately, a global search establishes which parameters matter at all, and each of them is then examined on its own.

No parameter is found to be uniformly beneficial: each reduces the cost of one stage only by raising that of another, so that the optimum lies at an interior balance rather than at either extreme, and its location is contingent on both the problem instance and the host architecture. Trade-offs of geometric origin are captured in closed-form models, while the remainder are attributed to the memory hierarchy. The contribution is therefore an explanatory account of the observed parameter behaviour, together with the foundation on which an automatic selection could be constructed.

\vspace{1cm}
\noindent\textbf{Keywords:} FINUFFT, nonuniform FFT, parameter selection, performance analysis
